# SVG Compatibility Fixtures

These files are LaserTab import fixtures for common SVG exporter styles:

- `compat_basic_shapes.svg`: basic geometry elements.
- `compat_css_inheritance.svg`: inherited presentation attributes and simple CSS selectors.
- `compat_fill_only_icon.svg`: fill-only icon artwork converted to laser outlines.
- `compat_defs_use_symbol.svg`: `defs`, `symbol`, `use`, `href`, and legacy `xlink:href`.
- `compat_nested_transforms.svg`: nested transform chains.
- `compat_path_commands_subpaths.svg`: mixed path commands and separated subpaths.
- `compat_scoped_css_units.svg`: scoped descendant CSS selectors, CSS color functions, alpha hex colors, and unit-suffixed lengths.
- `compat_nested_svg_markers.svg`: nested SVG viewports plus marker arrowheads expanded from `defs`.

They are intended for manually checking LaserTab SVG import behavior.
