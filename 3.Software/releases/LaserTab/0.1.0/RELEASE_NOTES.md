# 0.1.0

This is the first public LaserTab desktop release for X-Laser users.

## Included Artifacts

The executable and installer files are distributed as GitHub Release assets:

- `LaserTab.exe`: portable Windows executable. Download and run directly.
- `LaserTab_0.1.0_x64-setup.exe`: Windows installer.
- `LaserTab_0.1.0_x64_en-US.msi`: Windows MSI installer.

Update signatures are embedded in the public updater manifest and are not distributed as user-facing release assets.

## Highlights

- SVG and ILD source loading with recent-file tracking.
- SVG-to-ILD export through a native save dialog.
- Command preview plus physical projection simulation modes.
- Multi-frame ILD playback support.
- Adjustable output quality, XY transform, scanner response, laser power, and spot size.
- Automatic update checks for future LaserTab releases.
